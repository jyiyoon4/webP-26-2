# 하위 페이지 공통 구조

모든 하위 페이지가 같은 틀을 쓴다.

1. 유틸 바 + 헤더 (메인과 같다)
2. **서브 비주얼**: 파란 네트워크 패턴 배너. 모든 페이지가 같은 이미지를 쓴다.
3. **현재 위치 바**: 🏠 > 1단계 ▾ > 2단계 ▾ (드롭다운) + 글자 축소 / 확대 / 인쇄 버튼
4. **페이지 제목** (가운데) + 좌우 화살표 (이전/다음 페이지)
5. 본문
6. 하단 **이전/다음 메뉴 버튼** (예: "◀ 커뮤니티 · SM중심대학사업단 ▶")
7. 외부 링크 띠 + 푸터

## 본문 유형
| 유형 | 페이지 |
|---|---|
| 글 | 교육목표, 학과장 인사말, 졸업 후 진로 |
| 표 | 학과연혁, 교육과정, SM-CDR |
| 카드 목록 (게시판형) | 교수소개, 명예교수, 연구실소개, 포토갤러리 |
| 게시판 목록 | 공지사항, 학과소식, 취업정보, 상명공지 |
| 달력 | 학사일정 |
| 지도 | 학과사무실안내 (카카오맵) |
| 이미지 1장 | 졸업작품전 |

> [!tip] 우리 사이트에 주는 시사점
> 이전/다음 화살표, 글자 확대, 인쇄 같은 부가 기능이 많다. 정작 페이지 안에서 **찾는 기능**(탭, 필터, 목차)은 약하다.
