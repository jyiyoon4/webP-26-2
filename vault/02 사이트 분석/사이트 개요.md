# 사이트 개요

- 이름: 상명대학교 소프트웨어학과 (천안캠퍼스)
- 주소: `https://software.smu.ac.kr/software/index.do`
- 형태: 대학 공용 CMS의 학과 사이트. 다른 학과 사이트와 같은 틀을 쓴다. 본문 영역 ID는 `#jwxe_main_content`이다.

## 메뉴 구조 (IA)

```
메인
├ 학과안내      교육목표 · 학과장인사말 · 학과연혁 · 졸업 후 진로 · 학과사무실안내
├ 교수소개      교수소개 · 명예교수소개
├ 연구실소개    (단일)
├ 학사안내      학사일정 · 교육과정 · SM-CDR
├ 커뮤니티      공지사항 · 학과소식 · 취업/공모전/산학정보 · 상명공지 · 포토갤러리
├ 졸업작품전    (단일)
└ SM중심대학사업단 → swai.smu.ac.kr (외부, 모바일 메뉴에서는 JS로 숨김)

유틸 메뉴: 상명대학교 · LOGIN · 샘물포털시스템 · SITEMAP
```

- 메뉴 7묶음, 하위 페이지 약 19개
- **학과 소개와 게시판이 섞여 있다.** 진로 관련 정보가 '학과안내 > 졸업 후 진로'와 '학사안내 > SM-CDR'에 나뉘어 있다.

## 사용 기술 (원본)
- jQuery **1.9.1** (2013), jQuery UI 1.11.4, Owl Carousel(슬라이더), Froala 에디터
- 폰트: Noto Sans KR
- `<meta name="viewport" ... user-scalable=no>`: 모바일에서 손가락 확대가 막혀 있다(접근성 ❌).
- 버튼 · 아이콘 대부분이 이미지(`.png/.gif`)다.
- 반응형: 모바일에서 햄버거 메뉴가 나오고 카드가 세로로 쌓인다.
- 접근성 기본: '본문 바로가기' 링크 있음, 링크마다 `title` 있음
