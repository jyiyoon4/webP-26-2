# 문제점 목록 (전체)

> 기획안에 넣을 3가지는 [[불편한 점 TOP3]]로 추렸다. 이 노트는 근거 자료 전체다.

## 🧭 정보 구조 (찾기 어려움)
- [ ] **진로 정보가 두 곳에 나뉨**: '학과안내 > 졸업 후 진로'와 '학사안내 > SM-CDR'
- [ ] **교수와 연구실이 분리됨**: 교수 카드의 🏠 아이콘이 연구실 링크라는 걸 알기 어렵다. 연구실 메뉴에는 2곳만 있다.
- [ ] 고3이 "뭘 배우고 → 누가 가르치고 → 어디로 가나"를 보려면 메뉴 **4곳**(교육과정 · 교수 · 연구실 · 진로)을 돌아다녀야 한다.
- [ ] 메뉴 7묶음에 학과 소개와 게시판이 섞여 있다.
- [ ] 학사일정은 학교 전체 일정이다. 학과 고유 일정이 거의 없다.

## 🕸️ 오래됨 · 비어 있음 · 깨짐
- [ ] **메인 '포토갤러리' 카드 → `portfolio.do` 404 오류** (메뉴의 포토갤러리는 `photo.do`)
- [ ] **졸업작품전 페이지 = 캠퍼스 항공사진 1장**. 작품 정보가 없다. → [[졸업작품전]]
- [ ] **학과연혁이 2017.09에서 멈춤**. 현재 교수진(양희경 · 배동성 · 성광제 · 박한샘 · 이성주) 부임 기록이 없다. → [[학과연혁]]
- [ ] 교육목표의 'PRIME 사업 선정' 문구는 2016~2018 사업이라 오래됐다.
- [ ] 메인 취업정보 목록에 **2018년 글**(네이버 캠퍼스 핵데이 2018 윈터)이 떠 있다.
- [ ] 학과소식 마지막 글은 2019년(내용은 2015~2019), 포토갤러리 마지막은 2023년이다. → [[학과소식·포토갤러리]]
- [ ] 메인 슬라이더는 **1장뿐인데** 이전/다음/정지 버튼이 있다.
- [ ] 로고 링크는 `index.jsp`, 실제 홈은 `index.do`로 서로 다르다.

## 📄 콘텐츠 품질
- [ ] 교수 정보 편차: 배동성 교수는 **세부전공 없음**, 박한샘 교수는 **사진 · 연락처 없음**, 명예교수는 세부전공 한 줄뿐이다. → [[교수진]]
- [ ] 연구실 사진: LOG:Lab은 기본 이미지(`eximg.jpg`)를 쓴다. → [[연구실]]
- [ ] 연구실 위치 표기가 제각각이다. DSPlab '본관 404B호', LOG:Lab '본관C404a호'. 교수 연구실은 '한누리관'으로 표기한다.
- [ ] 졸업 후 진로는 목록만 있고 수치나 사례가 없다. → [[졸업 후 진로]]
- [ ] 교과목 해설 페이지의 '학수번호' 칸에 과목 코드 대신 **'1전선'이 잘못 표시**된다.
- [ ] 교육과정 '전체보기' 표 첫 줄에 공과대학 과목(취업과창업, 3학년 2학기)이 정렬과 무관하게 끼어 있다.
