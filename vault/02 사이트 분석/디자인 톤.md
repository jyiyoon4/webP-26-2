# 디자인 톤 (원본)

## 색상
| 용도 | 값 | 비고 |
|---|---|---|
| 본문 글자 | `#333333` | |
| 강조 제목 / 카드 | `rgb(151,173,214)` ≈ `#97ADD6` | 연한 파랑. '공지사항' 활성 탭, 바로가기 카드 |
| 유틸 바 배경 | `rgb(238,242,251)` ≈ `#EEF2FB` | |
| 푸터 링크 띠 | 진한 남색 (≈ `#1B2F6E` 계열) | 화면에서 눈으로 추정 |
| 푸터 배경 | `#F9F9F9` | |
| 서브 비주얼 | 파란 네트워크/육각형 패턴 이미지 | |

## 타이포
- 폰트: **Noto Sans KR**
- 본문 15px, GNB 25px(굵게), 섹션 제목 30px

## 인상
- 깔끔하지만 **CMS 기본 틀**이라 학과의 개성이 없다.
- 사진 위주의 큰 카드, 이미지 버튼 → 2010년대 중반 느낌
- 상명대 공식 색(남색 계열)은 유지되어 있다.

> [!success] 결정: **A. 학교 남색 유지 + 현대화** ([[결정할 것]])
> - 유지: 남색 계열 주조색, 연한 파랑 보조색
> - 바꿀 것: 이미지 버튼 → CSS/SVG, 큰 사진 카드 → 정보 중심 카드, 넉넉한 여백, 모바일 우선
> - 원본 화면 · 코드는 복사하지 않는다. 색 계열만 참고하고 레이아웃은 새로 설계한다. ([[안 B 조건]])
