# 페이지 구성안 (초안)

> 원칙: 메뉴를 다 만들지 않는다. 사용자에게 중요한 **4~6쪽**만 골라 다시 설계한다. ([[기말 프로젝트 개요]])

## 새 사이트 구조
```
메인
├ 학과 소개      ← 교육목표 + 학과장 인사말 + 연혁 + 학과사무실
├ 교육과정       ← 교육과정 + 교과목 해설
├ 교수 · 연구실  ← 교수 + 명예교수 + 연구실
├ 졸업 후 진로   ← 졸업 후 진로 + SM-CDR
└ (학과 생활)    ← 학사일정 · 공지 바로가기 · 사무실   [선택]
```

## 페이지별 계획
| # | 페이지 | 재료 | 핵심 UI | JS 기능 |
|---|---|---|---|---|
| 1 | **메인** | 인사말 핵심 문구, 각 페이지 요약 | 히어로 + 3대 질문 카드("무엇을 배우나 / 누가 가르치나 / 어디로 가나") | 모바일 메뉴 열고 닫기 |
| 2 | **학과 소개** | [[학과소개·교육목표]], [[학과장 인사말]], [[학과연혁]], [[학과사무실]] | 교육목표 4개 카드, 주 6시간 강조, 연혁 타임라인 | 연혁 시대별로 접고 펴기 |
| 3 | **교육과정** | [[교육과정 2026]], [[교과목 해설]] | 학년 탭 → 학기별 과목 카드 | **학년 탭**, 전공선택/전공심화/PBL **필터**, 과목을 누르면 **해설 펼침** |
| 4 | **교수 · 연구실** | [[교수진]], [[연구실]] | 교수 카드 그리드. 연구실이 있는 교수는 배지 표시 | **카드 강조**, 누르면 상세(학위 · 경력 · 연구 주제) 펼침 |
| 5 | **졸업 후 진로** | [[졸업 후 진로]], [[SM-CDR]] | 진출 기업 리스트, 진로 분야 8개, 트랙 카드 6개 | 트랙 카드 강조 / 펼침 |
| 6 | 학과 생활 (선택) | [[학사일정]], 공지 링크, [[학과사무실]] | 재학생 바로가기 모음 | - |

## 공통
- 헤더(로고 + 메뉴 5~6개), 모바일 햄버거 메뉴
- 푸터: 주소, **예시 연락처**, 이미지 출처 표기, "원본: software.smu.ac.kr" 안내
- 반응형(모바일 우선), 손가락 확대 허용
