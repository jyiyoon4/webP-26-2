# 학사일정

- 형태: 월별 달력 / 리스트 보기, 2018~2027년 선택
- 분류 탭: **학사일정 · 행사일정 · 소프트웨어학과(천안)일정**
- 2026년 11월 표시 내용(학사일정 탭)
  - 11/7, 11/14 주간: 2026-2학기 중간강의평가
  - 12/5 주간: 2026-2학기 기말강의평가

## 분석
- 학교 공통 일정을 그대로 보여준다. **학과 고유 일정은 거의 보이지 않는다.**
- 실시간 연동은 범위 밖이다.
- ✅ **결정: 링크 + 정적 스냅샷 둘 다** ([[결정할 것]])
  - 수집 시점의 일정 몇 개를 정적으로 보여주고 **"2026-11-26 기준"**을 표기한다.
  - 바로 아래에 "전체 학사일정 보기 → 원본 사이트" **링크**를 둔다.
  - 스냅샷 후보: 2026-2학기 중간강의평가(11월 초), 기말강의평가(12월 초). 필요하면 구현 전에 12월 일정을 다시 수집한다.
- 재학생용 '학과 생활' 페이지를 만들 경우 후보 재료다. → [[페이지 구성안]]
