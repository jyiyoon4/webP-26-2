# SM-CDR (원문)

> 2026학년도 SM-CDR 나비오름. 서울/천안캠퍼스 탭이 있고, 천안캠퍼스 기준이다.

| 학과명 | CDR |
|---|---|
| 소프트웨어학과 | 네트워크/사물인터넷(IoT) 소프트웨어 전문가 |
| 소프트웨어학과 | 블록체인, 정보보호 및 보안 전문가 |
| 소프트웨어학과 | 빅데이터 소프트웨어 전문가 |
| 소프트웨어학과 | 임베디드소프트웨어 전문가 |
| 소프트웨어학과 | 데이터베이스 전문가 |
| 소프트웨어학과 | 빅데이터 및 인공지능 소프트웨어 전문가 |

> 본 CDR은 학과별 교육과정 개편에 따라 변경될 수 있음

## 분석
- 'CDR'이 무엇의 약자인지 원본에 **설명이 없다**. 고3에게는 낯선 용어다.
  - 우리가 풀어서 설명을 지어내면 안 된다. '진로 트랙'처럼 화면 제목만 바꾸고 원문 명칭을 함께 적는다.
- 원본 표기 오타: 'loT'(소문자 L)가 있다. 사이트에서는 'IoT'로 표기한다.
- 6개 트랙 → **카드 6장** UI에 적합하다.
- ⚠️ 트랙 ↔ 과목 매칭은 원본에 없으므로 금지
